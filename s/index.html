ReCall runs on Android phones. Open this page on the phone (scan the QR code with its camera).

Install in 3 steps

  1. Samsung phones: open Settings › Security and privacy › Auto Blocker and turn it off. (Other phones: skip this.)
  2. Tap Download ReCall. If the browser warns about the file, tap Download anyway. Download ReCall
  3. Open the downloaded file. When asked, allow your browser to install unknown apps, then tap Install.

Then: scan your business's setup QR code again with the camera (or tap Open in ReCall above). ReCall opens already set up for the business.

After setup

  • Business phone: allow Call log, Notifications and "Run in background". On Samsung also set Settings › Apps › ReCall › Battery › Unrestricted.
  • Owner view: view-only. It never reads the owner's own calls. Missed-call alerts can be turned on in ReCall › Settings.
  • Updates arrive inside the app (an "Update available" banner).

Privacy: a setup code sits after the # in this page's address. Browsers never send that part to any server, and this page has no analytics, cookies or third-party content. No setup code? Ask your ReCall provider for the business's setup sheet.
